# Procedural model library

The procedural library contains all 25 requested models. The final meshes have supported iron sights and grip joints, visible sedan glazing, fitted headwear, and a seated toilet rim. All are generated by `models/build_models.py` using the existing `Model` primitives and flat-colour materials.

This change updates the model source, Blender scene, exported GLB, previews, and model documentation only. It makes no JavaScript, HTML, or CSS changes.

The 11 weapons use `Weapons`; 10 props use `Props`; the four head accessories use `Accessories`, included in `EXPORT`. Accessories share the existing Head origin and face +Y. The weapon display continues at y = -1.5 on a 0.5 m grid, reserving an extra slot for the crossbow's width. New props have separate display positions. No pre-task model, helper, or material definition was changed.

The four additional materials are `TrafficOrange`, `Ceramic`, `SandCanvas`, and `PoliceNavy`. Other surfaces reuse existing materials. The car's four tyre cylinders are mesh components inside the single `Car` object.
